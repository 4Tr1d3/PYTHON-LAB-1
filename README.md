# Консольный набор утилит

Проект на Python, содержащий калькулятор и конвертер единиц измерения.

## Возможности

### Калькулятор

Калькулятор поддерживает:

* целые и дробные числа;
* сложение `+`;
* вычитание `-`;
* умножение `*`;
* деление `/`;
* унарные `+` и `-`;
* круглые скобки;
* приоритет операций;
* игнорирование пробелов.

Пример:
python -m toolkit calc "2 + 3 * 4"


Результат:
14

### Конвертер

Поддерживаются следующие единицы измерения.

**Длина:**

* `mm` — миллиметры
* `cm` — сантиметры
* `m` — метры
* `km` — километры

**Масса:**

* `g` — граммы
* `kg` — килограммы

**Температура:**

* `c` — градусы Цельсия
* `f` — градусы Фаренгейта
* `k` — Кельвины

Пример:
python -m toolkit convert 100 --from cm --to m


Результат:
1

Единицы измерения не чувствительны к регистру.

Например:
python -m toolkit convert 1 --from KM --to m

### Округление результатов

Для вычислений калькулятора и конвертера используется Decimal.

Результат округляется до 8 знаков после запятой с использованием ROUND_HALF_UP.

Ненужные нули в конце дробной части удаляются.

Результат выводится в обычной десятичной записи.

Примеры:

5.00000000 → 5
5.12000000 → 5.12
1.234567895 → 1.2345679
50 mm → km → 0.00005

## Обработка ошибок

Программа обрабатывает:

* пустые выражения;
* недопустимые символы;
* пропущенные операнды;
* неправильную последовательность операторов;
* деление на ноль;
* неизвестные единицы измерения;
* несовместимые единицы;
* температуру ниже абсолютного нуля;
* некорректные числовые значения.

## Установка

Перейдите в корневую папку проекта:

LAB 1/

Создайте виртуальное окружение:

python -m venv .venv

Активируйте виртуальное окружение.

Для Windows PowerShell:

.\.venv\Scripts\Activate.ps1

ИЛИ

.\.venv\bin\Activate.ps1

Установите проект и инструменты для разработки:

python -m pip install -e ".[dev]"


## Запуск

Для просмотра общей справки:
python -m toolkit --help

Для справки по калькулятору:
python -m toolkit calc --help

Для справки по конвертеру:
python -m toolkit convert --help

### Калькулятор
python -m toolkit calc "2 + 3 * 4"

### Конвертер
python -m toolkit convert 100 --from cm --to m
